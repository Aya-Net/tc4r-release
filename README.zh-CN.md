# 神秘核心：释放（TC4R）

**探索万物，研习炼金、注魔与魔法构装。**

[English](README.md) · 简体中文

[下载与版本发布](https://github.com/Aya-Net/tc4r-release/releases)

**神秘核心：释放（Thaumic Core for Release，TC4R）**是一款受 Thaumcraft 4 启发的 Minecraft 魔法模组，模组 ID 为 **`tc4r`**。该名称不代表与 Thaumcraft 存在官方关联。

扫描世界，发现万物蕴含的要素，通过研究逐步解锁知识，搭建自己的炼金工坊。探索法杖与魔法能量，用注魔制作装备，让魔法构装协助工作。

这里提供 **TC4R 本体运行 JAR** 及同批次的 **原生 API JAR**。当前模组版本为 **1.0**；文件名同时标明 Minecraft 版本与加载器。

## 你可以体验什么

- **研究与发现**：观察世界，沿着相互关联的研究体系拓展知识。
- **法杖与魔法能量**：探索能量节点，组合法杖，将研究成果化为实际能力。
- **炼金与注魔**：提取、运输源质，搭建工坊，制作魔法工具与装备。
- **构装与探索**：让构装协助完成工作，并面对危险研究带来的后果。

| 1.21.1 | NeoForge 21.1.248 或更高 | 21 | `tc4r-1.21.1-neoforge-1.0.jar` | `tc4r-1.21.1-neoforge-1.0-api.jar` |

在[发布页](https://github.com/Aya-Net/tc4r-release/releases)选择与你的 Minecraft 版本和加载器完全对应的文件。发布说明中附有 SHA-256 校验和。

## 安装方法

1. 按上表创建实例，使用对应的 Minecraft、加载器与 Java 版本。
2. 按下表要求安装对应版本的 **Curios** 与 **TerraBlender**。
3. 下载运行 JAR，直接放入实例的 `mods` 文件夹。
4. 更新时替换旧的 TC4R 运行 JAR，然后重启游戏或服务器。

本次发布包含本体模组。附属需使用配套的 TC4R 版本、Minecraft 版本与加载器。

## 必需前置

下表范围取自发布 JAR 的加载器元数据。请安装适用于相同 Minecraft 版本与加载器的文件。

| 前置 | Minecraft 1.20.1 · Forge | Minecraft 1.21.1 · NeoForge |
| --- | --- | --- |
| [Curios](https://modrinth.com/mod/curios/versions) | `>= 5.14.1+1.20.1`，`< 6` | `>= 9.5.1` |
| [TerraBlender](https://modrinth.com/mod/terrablender/versions) | `>= 3.0.1.10`，`< 4` | `>= 4.1.0.8` |

## 外观与资源

TC4R 采用单色贴图与 8-bit 风格音效，以简洁的色块和复古音色呈现独特的魔法氛围。
